# Fart Blaster

A small browser arcade game built in pure HTML, CSS, and JavaScript.

## How to run

Open `index.html` in a browser or serve the folder with a local static server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Press `Space` to fire a fart blast
- Click or tap the canvas to fire
- Survive as long as possible and shoot down incoming creatures

## Notes

This is intentionally styled like an 8-bit arcade shooter with retro CRT-inspired visuals and simple generated audio.
